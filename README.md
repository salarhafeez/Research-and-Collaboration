## 📋 Project Description

The Research and Collaboration System is an object-oriented software system designed to manage and support research activities in an academic environment. The system provides a structured platform where researchers can create research projects, upload and manage research papers, collaborate with other users, and handle the review and approval process efficiently.

The system supports multiple user roles including Admin, Researcher, Collaborator, Reviewer, and Visitor. Each role has well-defined responsibilities and access privileges, ensuring role-based access control and secure interaction with the system. The design of the system follows Object Oriented Analysis and Design principles and is developed in a phased manner using UML diagrams and Java implementation.

This project is developed as part of the Object Oriented Analysis and Design course and demonstrates the application of use case modeling, class design, and object-oriented programming concepts.

---

## 👥 Actors and Roles

- **Admin:** Manages users, research projects, system monitoring, and content moderation.
- **Researcher:** Creates and manages research projects and research papers.
- **Collaborator:** Joins projects, contributes research material, and communicates with researchers.
- **Reviewer:** Reviews submitted research papers, provides feedback, and approves or rejects papers.
- **Visitor:** Browses and searches publicly available research papers.

## 🧩 Object Oriented Design Overview

### UML Diagrams
- **Use Case Diagram:** Represents interactions between actors and the system (Phase-1).
- **Class Diagram:** Defines classes, attributes, methods, and relationships (Phase-2).

### OOAD Concepts Applied
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Association and dependency relationships
- Role-based access control
